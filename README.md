# 📦 Supply Chain Performance Analysis

---

## 📌 Project Overview
This project analyzes the supply chain performance of a global e-commerce company, focusing on delivery delays and their impact on profitability.

The goal is to identify inefficiencies in the supply chain and provide data-driven insights to improve operational performance.

---

## 🚨 Business Problem
The company is facing inconsistent delivery performance, leading to:

- High percentage of late deliveries  
- Poor customer satisfaction  
- Increased operational costs  
- Unstable profitability  

---

## 🎯 Objective
- Analyze delivery delays and patterns  
- Identify bottlenecks in the supply chain  
- Measure impact of delays on profit  
- Generate key KPIs  
- Provide actionable business insights  

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy)  
- Matplotlib & Seaborn  
- Jupyter Notebook  

---

## 📊 Dataset

- 📁 Full dataset is included in this repository as a **compressed ZIP file**  
- The dataset contains order-level information such as shipping details, delivery status, and profitability metrics  

⚠️ Note: Dataset is compressed due to GitHub file size limitations.

---

## 🔍 Analysis Performed

### ✔ Data Cleaning
- Removed unnecessary and sensitive columns  
- Handled missing values  
- Converted date columns to datetime format  

### ✔ Feature Engineering
- Created **Order Processing Time**  
- Calculated **Delivery Delay**  
- Generated **Delay Flag**  
- Extracted **Month, Day, Hour features**  

### ✔ KPI Calculation
- Total Orders  
- Late Deliveries  
- On-time Delivery %  
- Delay Percentage  
- Profit at Risk  

### ✔ Bottleneck Detection
- Identified delays across:
  - Shipping Modes  
  - Regions  
  - Product Categories  

### ✔ Root Cause Analysis
- Analyzed factors contributing to delays:
  - Shipping inefficiencies  
  - Regional logistics issues  
  - Customer segment variations  

### ✔ Time-Based Analysis
- Delay % by:
  - Month  
  - Day of Week  
  - Hour of Day  

---

## 📈 Key Insights

- Over **50% of orders are delayed**  
- Certain shipping modes contribute to higher delays  
- Specific regions show consistent inefficiencies  
- Delays significantly impact profitability  
- Peak delays occur during specific hours and days
